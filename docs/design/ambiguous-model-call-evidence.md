# Ambiguous model-call evidence

Retain a bounded diagnostic value on the correlated terminal observation and
persist it atomically with the model-call outcome. Existing call context and
configuration records identify the request. Typed runtime loss facts identify
response progress and the classification point; adapter-redacted detail supplies
bounded explanation. Terminalization without a runtime report records its
absence and prior call state. Evidence is observational and grants no retry or
outcome authority. No raw request archive, stream journal, new read API or
policy is built.
