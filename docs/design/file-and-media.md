# File and media interpretation design

Image presentation is built in
[file and media interpretation](../spec/file-and-media.md).

## Unbuilt presentations

Audio and general-file views may extend the provider-neutral reference path with
corresponding model-adapter capabilities and translations. Format detection and
MIME dispatch remain in sandboxed workers. Source, view, process and target
bounds apply before publication and model preparation.

OCR, transcription and a classification cache remain undecided in
[open questions](../open-questions.md). Web thumbnails may reuse the
deterministic derived image path; the web UI does not request these views.
