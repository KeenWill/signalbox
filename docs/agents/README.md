# Agent process documents

The documents in this directory govern how agents work on the repository:
operating rules for autonomous runs, the pullable [work backlog](backlog.md),
the [style rules](testing-style.md) that bind their tests, and the
non-authoritative [web-campaign coordination map](web-campaign.md). The system
itself is documented in [docs/](../) and [docs/spec/](../spec/); the
repository-wide entry point for agents is [AGENTS.md](../../AGENTS.md).
